## ✨ Features

| Feature | Description |
|---------|-------------|
| 🏦 **Multi‑Account Support** | Create multiple accounts (Own / Funded), switch between them |
| 📸 **Screenshot‑Mandatory** | Every trade requires a screenshot – no more forgetting to document |
| 📈 **Auto P&L Calculation** | P&L automatically calculated based on instrument, lot size, open/close price |
| 📊 **Real‑Time Dashboard** | Total trades, wins, losses, win rate, total P&L, and current balance |
| 🖼️ **Trade Gallery** | View all trade screenshots in a beautiful grid layout |
| 📅 **Trading Calendar** | Colour‑coded calendar (green = profit, red = loss) |
| 📉 **Analytics Charts** | Monthly P&L line chart + Win/Loss doughnut chart |
| 📄 **PDF Export** | Export trades as a professional PDF with logo, date range, and watermark |
| 🌗 **Dark / Light Mode** | Full support for both themes with smooth transitions |
| 📱 **Fully Responsive** | Works perfectly on desktop, tablet, and mobile devices |
| 💾 **Local Storage** | All data is stored locally in your browser – no server needed |

---

## 🎨 Design Highlights

- iOS‑style glassmorphism with frosted glass effect
- Luxury 3D logo – Hexagonal badge with brushed gold & gunmetal metallic texture
- Professional colour scheme – Blue accents, green for profits, red for losses
- Smooth animations – Fades, slide‑ins, and hover effects
- Custom iOS‑style modals – No browser alerts, all custom confirmation popups

---

## 🛠️ Technologies Used

- HTML5 – Semantic markup
- CSS3 – Glassmorphism, flexbox, grid, animations, dark mode variables
- JavaScript (ES6+) – Vanilla JS, no frameworks
- Chart.js – Interactive charts for analytics
- html2pdf.js – PDF generation with custom styling
- LocalStorage – Persistent data storage
